# Map Menu (R.E.P.O. mod)

An admin menu mod for **R.E.P.O.** (BepInEx plugin).

## Download

👉 **[Download the latest version](https://github.com/Acherchu/repo-map-menu/releases/latest)**: get `MapMenu-<version>.zip` under **Assets**.

## Install (Thunderstore Mod Manager)

1. Open **Thunderstore Mod Manager**, pick **R.E.P.O.** and a profile.
2. Make sure **BepInExPack** is installed in that profile (get it from the **Online** tab if not).
3. Go to **Settings → Import local mod** and choose the downloaded zip.
4. Start the game **modded**.

**Updating?** Remove the old Map Menu first, then import the new zip.

**Joining late?** Also install **LateJoinPlus** (by RicketyWrecked) from the Online tab. With it, every room loads properly when you join mid-game.

## Keys

| Key | What it does |
|---|---|
| **F7** | Open the admin menu |
| **F5** | Time stop (host): everyone and everything freezes, even mid-air. F5 again to resume |
| **V** | Fly (WASD, Space up, Ctrl down, Shift fast) |
| **G** | God mode (heals you and you can't take damage) |
| **4** | 4th inventory slot (host) |
| **E** | Place a player you're holding (Bring Players) |
| **Delete** | Despawn the item you're looking at |
| **M** | Players panel (host): every player's head and name, with **DELETE** (they vanish into spectating, and stay gone across levels) and **ADD** (back in, next to you) |
| **Shift + Right click** | On a player: open a menu for just that player (left click still picks people up) |
| **F9 / F10** | When someone joins late: **KEEP** or **DELETE** them (popup bottom left, after they've loaded in) |

## Admin menu (host only)

- **Go to a Map**: send the lobby to any shop, game map, or the King of the Losers arena. In the lobby (before Start), pick one to make the run **start** there.
- **Items**: search and spawn any item, Spawn Scout, Spawn Gun, Despawn All Items.
- **Players / Monsters**:
  - Players: Kill, Revive, Heal, Blind, TRAUMA, PINBALL, SEND TO HELL, Kill Everyone, Blind Everyone.
  - Torture extras: **FLASHBANG** (25 stun grenades all round them) and **ORBITAL STRIKE** (one grenade splits into 81 that land in a huge target pattern and all blow at once).
  - Monsters: spawn any monster; Kill, Heal, Stun, TRAUMA, PINBALL, SEND TO HELL; Kill All / Stun All. Spawned monsters stay put and work in the shop.
  - PINBALL: they bounce off every wall like a rubber duck; each hit explodes for 10 damage, until they die.
- **Third Person** on/off.
- **GRAB ME = DEATH** on/off: when on, anyone who picks you up gets launched into a wall and blows up.
- **Bring Players**: pick players and they stack frozen at your crosshair; press E to place them one at a time.
- **NUKE**: warning, red flashes, then 200 grenades with random fuses across the map. Survive the blasts and you live.

Also included: super guns (5x bullets, 20,000 damage, no cooldown), only the host can make the truck leave, inventory works in the shop, lobbies hold up to 20 players, flushing a toilet makes it explode 2.5 s later, dead players' heads under a shop extraction point revive instantly, and (with GRAB ME = DEATH on) anyone who grabs the host gets launched into a wall and blows up.
The GAMBLE's 1 minute of maxed stats and the upgrade page's **-1** set stats to the exact right number for everyone, straight away.

## Your own menus (players with the mod)

- A **SCOUT BATTLES** intro the first time the main menu loads: a black hole forms, the title flies together, then it explodes into the menu.
- A new **main menu**: a foggy forest with clouds, an old cabin and a gravel path, and a yellow duck with a crown sitting on a branch swinging its legs.
- The **lobby** shows the inside of a shop with a Scout parked in it.

Players without the mod still see almost everything the host does to them. You need the mod to open the menu, fly or use god mode yourself.
